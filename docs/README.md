# Vela documentation

How to use Vela Maps, what it sends where, and how each part works. The search box finds
anything, from "offline routing" to a class name like `NavSession`.

This folder is the source of the documentation website at
<https://pimpinpumpkin.github.io/Vela/docs/>, rebuilt from `main` on every push.
